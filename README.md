A Discord bot and web dashboard for World of Warcraft guild management.

🚧 Project Status

This project is currently under active development.
New features are being implemented regularly, and the codebase is continuously evolving.

Features (Planned & In Progress)
Character registration
Raid sign-ups
Guild roster management
Attendance tracking
Discord integration
React web dashboard
NestJS REST API
PostgreSQL database
Tech Stack
Frontend: React, TypeScript
Backend: NestJS, TypeScript
Database: PostgreSQL, Prisma ORM
Discord: Discord API / Necord

Note: This repository is a work in progress. Features, architecture, and documentation may change as development continues.
